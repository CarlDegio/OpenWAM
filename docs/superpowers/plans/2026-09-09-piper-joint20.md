# Piper joint-space Alpha fine-tuning implementation plan

**Goal:** Fine-tune the downloaded Alpha Foundation on the user's embedded-image LeRobot v2.1 Piper dataset, with a joint-space 20-D interface and the original 80-D model.

**Approved design:** Each arm is `[q1, q2, q3, q4, q5, q6, 0, 0, 0, gripper]`. Left/right blocks map to unified indices 0–9 / 34–43. Padding has zero values and false masks. Joint values are not rotations; all fourteen physical channels use independently fitted min-max statistics. Action row t remains the target paired with observation row t. State and action statistics are separate. No FK or unit conversion is inferred.

**Execution:** Implement inline in the current checkout on `codex/piper-joint20-finetune`; do not launch a production training job. Request an independent review after implementation.
